## 0.2.0 — 2026-11-19

### Вид
- **Цветные эмодзи** в просмотре — ✅ ❌ 🟡 ⚠️ 🚀, последовательности вроде 👨‍👩‍👧, «клавиши» 1️⃣. RichEdit рисует через GDI, где цветных шрифтов нет, поэтому просмотр дорисовывает цветную версию поверх через DirectWrite/Direct2D (Segoe UI Emoji); каждый эмодзи рисуется один раз и кешируется. `d2d1.dll`/`dwrite.dll` грузятся только для документа с эмодзи и только после первой отрисовки — скорость открытия та же. В режимах «Визуальный» и «Код» эмодзи идут шрифтом эмодзи, одноцветными.
- Эмодзи и символы (✔ ★ ☐ ⌘) больше не превращаются в пустые квадратики □: им явно задаются шрифты Segoe UI Emoji / Segoe UI Symbol (собственный подбор шрифта в RichEdit для многих из них ничего не находил).
- **Тёмная тема в цветах Markdown-просмотра Claude:** мягкий серо-графитовый фон вместо почти чёрного, чуть приглушённый основной текст, яркие заголовки, спокойные синие ссылки, серые шапка таблиц и фон кода.

### Исправления
- «Сделать программой по умолчанию для .md» открывала десятки окон «Выбор приложения». Теперь она открывает «Параметры Windows → Приложения по умолчанию»: в Windows 11 — страницу vibe-md-viewer, в Windows 10 — «Выбор стандартных приложений для типов файлов».
- Плашка «Картинок из интернета» спрашивала заново после каждой перерисовки, а ошибки были видны только в строке состояния. Теперь ответ запоминается для документа, а неудачная загрузка показывается в плашке с причиной.
- Визуальный режим: после расширения окна или смены ширины колонки рядом с новой вёрсткой оставалась старая (текст будто дублировался). Теперь редактор перерисовывается целиком.
- Ctrl+Shift+X вырезал выделение вместо зачёркивания.
- Часть `#…` адреса картинки уходила на сервер (`/a.png%23f` → 404).
- HTML в Markdown:
  - многострочные комментарии `<!-- … -->` и теги, разбитые на строки, теперь работают;
  - незакрытые `<iframe>`, `<svg>`, `<video>`… больше не прячут остаток документа, только до конца своего блока;
  - содержимое `<form>` скрыто, как и написано в документации;
  - `<li>`, `<hr>` и `$$…$$` внутри ячейки таблицы остаются в ячейке;
  - незакрытая `<a href>` в ячейке заканчивается вместе с ячейкой;
  - выравнивание незакрытого `<p align>` заканчивается с его блоком, а `</p>` больше не сбрасывает выравнивание `<div>`;
  - у «таблеток» `<code>`/`<kbd>` всегда оба отступа;
  - `<3` остаётся текстом;
  - в «разреженных» списках задач нет лишнего маркера.
- Автоссылки на почту `<me@example.com>` открывают почтовую программу.
- Подсветка Rust: `a != b` больше не красится как макрос.
- `lang = ru` с пробелами в `settings.ini` распознаётся при запуске.
- Таблица, которая ещё строится, учитывается в лимите 96 МБ, а RTF остаётся корректным, если лимит срабатывает внутри таблицы.

### Английский язык
- **Интерфейс на английском (по умолчанию) и русском** — кнопка **EN / RU** на панели переключает язык сразу и запоминает его (`lang=` в `settings.ini`). Установщик говорит на языке установленной программы.
- README и документация на двух языках: `README.md` / `docs/*.md` / `CHANGELOG.md` — английский, `*.ru.md` — русский; `AGENTS.md` — правила проекта для участников и ИИ-агентов; в zip — `README.txt` и `ПРОЧТИ.txt`.

### Новое имя: vibe-md-viewer
- Программа переименована из vibe-mdViewer в **vibe-md-viewer**: exe `vibe-md-viewer.exe`, папка установки `C:\Program Files\vibe-md-viewer`, настройки `%APPDATA%\vibe-md-viewer`, установщик `vibe-md-viewer-<версия>-setup.exe`.
- **Переезд с 0.1.x — автоматически при «Обновить»:** программа ставится в папку с новым именем, прежняя папка `vibe-mdViewer` удаляется (когда старая версия закрыта), записи реестра со старым именем убираются, настройки переносятся. Ключи `VibeMdViewer` и ProgID не менялись — выбор «программы по умолчанию» для `.md` сохраняется, Windows не спросит заново.

### Открытый исходный код
- Лицензия MIT; лицензии библиотек, входящих в программу, — `THIRD-PARTY-NOTICES.txt` (`scripts\notices.ps1`), кладётся в zip и в релиз.
- GitHub Actions: каждый коммит — юнит-тесты, сборка, самотест на живом окне; тег `vX.Y.Z` — сборка установщика из исходников тега и релиз с контрольными суммами и описанием из CHANGELOG. Только официальные действия `actions/*`.
- Тестовый документ с `кодом` в тексте заменён вымышленным.

### Безопасность (независимый аудит перед публикацией)
- Установка «для всех пользователей» — только в `C:\Program Files\vibe-md-viewer`: в своей папке её мог подменить обычный пользователь (родительская папка на втором диске доступна ему на запись). Своя папка — только при установке «для себя».
- Установщик копирует сам запущенный образ, а не файл по пути: подложить свой setup.exe в «Загрузки», пока идёт запрос UAC, больше нельзя.
- Картинка с узким сжатием одной стороны (`width=1 height=10000` у 16384×16000) больше не требует гигабайтов памяти.
- Подсветка синтаксиса: тысячи незакрытых `#[` / `${` больше не «вешают» окно.
- **Автосохранение не затирает изменения других программ:** если файл поменяли на диске (git pull, другой редактор), пока есть ваши правки, оно останавливается; Ctrl+S спрашивает, F5 перечитывает. Файл, прочитанный с заменой повреждённых символов, сам не сохраняется.
- Мелкое: путь установки с `..`, запасная защита от RTF, путь с «`» на стартовой странице, невидимые символы и `COM¹` в ссылках, `&` в `mailto:`, ещё два вида адресов локальной сети.
- GitHub Actions: действия закреплены по хешу, токен не сохраняется, сборка без права записи, публикация отдельно, подпись происхождения релиза.

### Проверки
- Тесты переезда: распознавание установки 0.1.x, новая папка, удаление только «нашей» папки, чистка старых записей реестра.
- Тесты на каждую находку аудита; самотест: автосохранение при изменении файла другой программой, переключение языка.
- **258 юнит-тестов**, они покрывают все модули. Среди них запрос WinHTTP к локальному серверу 127.0.0.1 (никогда не в интернет), отрисовка цветных эмодзи и каждая ветка `classify` для ссылок и путей.
- Самотест — 56 проверок. Добавлены:
  - кнопка «?» (настоящий щелчок);
  - перерисовка визуального режима после смены ширины;
  - плашка картинок;
  - клавиатурные сокращения и команды панели;
  - цветные эмодзи, в том числе после прокрутки.
- **Покрытие кода — 87,7% строк** (было 67,6%). `scripts\coverage.ps1` меряет юнит-тесты и самотест на инструментированной сборке. CI публикует отчёт и падает, если покрытие ниже 85%. Не покрыты системные диалоги, UAC и установка в Program Files.
- Тесты на настоящем RichEdit выполняются по одному (параллельно пиксельная проверка изредка видела пустой кадр).

## 0.1.3 — 2026-11-18

### Плавность
- **Прокрутка с частотой монитора.** Кадры ведёт цикл сообщений и ждёт обновления экрана (`DwmFlush`): на 144 Гц — 144 ровных шага в секунду. Раньше кадры шли по таймеру Windows (шаг ~15,6 мс): ~60 неровных кадров, на мониторе 144 Гц это выглядело как «мало fps».
- Кадр прокрутки вдвое дешевле: подложки `кода` больше не спрашивают у RichEdit положение каждой плашки на каждом кадре — геометрия считается один раз и сдвигается. Окно 2560×1380: в среднем 5,4 → 2,6 мс, худший кадр 13 → 6 мс (бюджет при 144 Гц — 6,9 мс).

### Ширина
- **Исправлено:** в широком режиме текст уходил правее блоков кода и линий под заголовками. Причины: таблица в RichEdit не бывает шире 22 дюймов (2112 px), а на мониторе 2560 px текст был шире; при масштабе ≠ 100% RichEdit умножает поля на масштаб; ширина пересчитывалась, только если окно изменилось больше чем на 24 px; полоса прокрутки появлялась после загрузки и сужала текст. Теперь колонка не шире 22 дюймов (лишнее — поровну по бокам), поля задаются с поправкой на масштаб, любое изменение ширины пересчитывается, полоса прокрутки есть всегда. Правый край текста, блоков кода и линий совпадает во всех режимах и при любом масштабе.
- Развёрнутое окно сразу открывается в нужном размере — документ рисуется один раз, без перескока ширины.
- `Код` в тексте переносится на новую строку целиком — без обрывка подложки в конце строки.

### Проверки
- Тест на настоящем RichEdit: поля при масштабе 50/100/150% и предел ширины таблицы.
- Самотест: правый край блоков = край колонки (окно шире на 13 px, масштаб 150% и 50%, узкая колонка); подложки `кода` после прокрутки кадрами совпадают с полной перерисовкой; прокрутка колесом идёт кадрами по частоте экрана (всего 41 проверка).
- `scripts\profile.ps1 -Size 2560x1380` — время кадра прокрутки (среднее, 95%, худшее).

## 0.1.2 — 2026-11-18

### Скорость
- **Загрузка по частям.** Сначала показывается часть документа с нужным местом, остальное догружается в фоне между событиями — окно не «подвисает». Документ на 275 КБ: открытие 520 → 60 мс до показа; смена темы 540 → 75 мс, переключение ширины 545 → 70 мс. Место чтения при смене темы/ширины/масштаба сохраняется.
- Переключение «Просмотр ↔ Визуальный» без правок — почти мгновенно (не перекрашиваем редактор заново и не переносим текст, если поля те же).
- **Плавная прокрутка** колесом, стрелками, PgUp/PgDn, пробелом (по пикселям, ~60 fps) вместо рывков RichEdit «по строкам» (блок кода прокручивался одним прыжком).
- Картинки при смене темы больше не декодируются заново.

### Вид
- `Код` в тексте — подложка по высоте текста со скруглёнными углами, как в VS Code (раньше RichEdit заливал всю высоту строки, и плашки на соседних строках сливались).
- Интервал между абзацами +2 px.
- Внизу документа есть место: последний абзац прокручивается до середины экрана.
- **Исправлено:** полоски с обрывками текста/кода сверху и снизу окна (поля RichEdit не перерисовывались при прокрутке).
- **Исправлено:** при масштабе ≠ 100% блоки кода и таблицы были уже текста; масштаб сбрасывался на 100% при каждой перерисовке.
- **Исправлено:** End не доводил до конца большого документа.

### Удобство
- Выделение текста мышью в просмотре (протянуть, Shift+щелчок, двойной щелчок — слово, Ctrl+A), копирование без служебных символов.
- Кнопки масштаба `− 100% +` на панели (100% — сброс), Ctrl+колесо работает и с сенсорной панелью.
- **Автосохранение** как в IDE: пауза в наборе, переход в просмотр, уход из окна, закрытие. Кнопок «Открыть»/«Сохранить» на панели больше нет (Ctrl+O / перетаскивание, Ctrl+S — сохранить сразу).

### Проверки
- Тест: документ, загруженный частями от середины, совпадает с загруженным целиком символ в символ.
- Самотест: выделение мышью, плавная прокрутка, автосохранение, разметка плашек кода (всего 34 проверки).
- `scripts\profile.ps1` / `--profile` — замер тяжёлых действий на большом документе.

## 0.1.1 — 2026-11-18

### Вид
- **Подсветка синтаксиса** в блоках кода — и в просмотре, и в редакторах («Визуальный», «Код»): Rust, C/C++/C#, Java, JS/TS, Go, Python, Shell, PowerShell, SQL, HTML/XML, CSS, JSON/YAML/TOML/INI, Lua, Ruby, diff. Свой лёгкий разборщик (`highlight.rs`): один проход, линейное время, блоки больше 256 КБ показываются без подсветки.
- Блоки кода без рамки, с полями, как на GitHub; межстрочный интервал 1.3.
- **Исправлено:** в тёмной теме цвета внутри блока кода не рисовались — RichEdit на очень тёмной заливке ячейки рисует весь текст одним «обратным» цветом. Фон блоков кода в тёмной теме чуть светлее порога (проверяет тест на настоящем RichEdit).
- `Код` в тексте: тоньше поля по бокам (тонкий пробел пропорциональным шрифтом вместо целого символа Consolas), отдельный спокойный цвет фона, размер относительно окружающего текста (в заголовке — крупнее); строки с кодом и без — одной высоты.
- Отступ над заголовком больше не растягивает фон `кода` в заголовке вверх.
- **Во всю ширину:** текст занимает всё окно; кнопка `→←` / `←→` на панели переключает на узкую колонку для чтения (запоминается). Первое окно — ~85% экрана по центру.

### Прочее
- `scripts\package.ps1` больше не удаляет установщики прошлых версий из `dist\` (нужны для проверки обновления).

## 0.1.0 — 2026-11-18

Первая версия.

### Подготовка к раздаче и аудит безопасности
- Обновление запуском нового exe: подмена файла в папке установки (даже если старая версия открыта), сохранение настроек и привязки `.md`, сравнение версий, запуск обновлённой программы.
- Установка как у обычного софта: `C:\Program Files\vibe-mdViewer` + HKLM через UAC (только на время операции, сам просмотрщик — с обычными правами); без прав администратора — установка «для себя» в `%LOCALAPPDATA%\Programs`. Настройки установленной программы — `%APPDATA%\vibe-mdViewer`.
- Установщик больше не перебивает чужую программу по умолчанию для `.md` — выбор за пользователем.
- **Исправлено:** подмена DLL рядом с exe — `uxtheme`, `dwmapi`, `bcryptprimitives` (не входят в KnownDLLs) грузились из папки программы до старта нашего кода; опасно для установщика, запущенного из «Загрузок» с правами администратора. Теперь при старте грузятся только KnownDLLs, остальное — отложенно и только из System32.
- Версия exe (свойства файла) берётся из `Cargo.toml`.
- `scripts\package.ps1`: zip для раздачи с инструкцией и SHA-256.
- **Исправлено:** RTF-инъекция в режимах правки — документ, начинающийся с `{\rtf`, разбирался RichEdit как RTF (подтверждено тестом). Текст теперь ставится и вставляется только через TOM как простой текст.
- **Исправлено:** падение при таблице больше 60 колонок (выход за границы массива).
- **Исправлено:** возможное падение при открытии поиска (повторный захват состояния во время создания диалога).
- **Исправлено:** маскировка расширения хвостовыми точками/пробелами (`setup.exe.`, `setup.exe%20`) обходила блок исполняемых файлов.
- Картинки из интернета: редиректы проверяются вручную (нельзя увести на `192.168.x.x`), нестандартные записи IP (`127.1`, `0x7f.0.0.1`) запрещены, имя сервера проверяется по DNS.
- Сохранение: временный файл с уникальным именем и `create_new` — подложенный файл или символическая ссылка не перезаписываются.
- Лимит памяти на картинку снижен до 256 МБ; глубина вложенных групп RTF ограничена; страховка от паник при разборе документа.
- `mailto:` — только адрес, тема, текст, копия (без `attach=`).
- Отключено OLE-перетаскивание в редактор; удаление через `cmd /v:off`.
- Тесты: «бомбы» (глубокая вложенность, 60 000 скобок, 300 колонок…), реестр и копирование при установке/обновлении, расширенный самотест (29 проверок).

### Установщик и удобство
- Окно мастера установки: `vibe-mdViewer-<версия>-setup.exe` (папка, «Открывать .md в vibe-mdViewer», «Запустить после установки»; для установленной программы — «Обновить» / «Переустановить» / «Удалить»).
- Тёмная тема по умолчанию.
- Стартовая страница: заметная плашка «Программа не установлена — Установить…»; кнопки «Визуальный»/«Код» на справке предлагают открыть свой файл вместо молчаливого отказа.

### Исправления по независимому аудиту
- **Высокая:** короткие имена 8.3 (`X~1.LIB` → `x.library-ms`) обходили блок опасных типов. Теперь тип проверяется по длинному имени в момент клика, а открыть можно только белый список безопасных типов; остальное — «Показать в проводнике». Пути с символическими ссылками отклоняются.
- `width`/`height` у `<img>` больше не могут вызвать выделение терабайт памяти.
- Лимиты против «взрыва» памяти: длина адресов, бюджет `data:`, ячейки таблиц, общий размер RTF; дедупликация и отмена устаревших задач картинок.
- Линейные алгоритмы вместо квадратичных: голые адреса, токенизатор HTML, сущности, группы RTF.
- Защищённые права на папку установки, `PING.EXE` по полному пути при удалении.
- Страховка от паник во всех оконных процедурах; исправлены падения при Ctrl+клике рядом с неразрывным пробелом и в панели после смены кнопок.
- Проверка подмены адреса не обходится невидимыми символами и «точками-двойниками»; незакрытая `<a href>` закрывается на границе абзаца.
- Нет бесконечных окон ошибки, если изменённый файл не читается; незакрытые `<form>`/`<template>` не прячут остаток документа.
- IPv4 внутри IPv6 (`::a.b.c.d`, 6to4) считается адресом локальной сети; общий лимит 30 с на загрузку картинки; `ES_NOOLEDRAGDROP`.

### Просмотр
- Нативное окно Win32 + RichEdit, без браузерного движка. Открытие документа ≈ 80–100 мс.
- CommonMark + GFM: заголовки, списки, задачи, цитаты, GitHub-предупреждения, таблицы с выравниванием, блоки кода, сноски, определения, front matter, формулы как код.
- Безопасное подмножество HTML: `<img>`, `<a>`, `<br>`, `<b>/<i>/<s>/<u>`, `<kbd>/<code>`, `<sub>/<sup>`, `<details>/<summary>`, `align="center"`.
- Картинки PNG/JPEG/GIF/BMP/WebP/ICO и `data:`; фоновое декодирование, кеш, подгонка под ширину.
- Кликабельные ссылки, якоря, переходы между `.md` с историей «Назад», голые адреса.
- Поиск, масштаб, светлая/тёмная тема (следует за системой), копирование, контекстное меню.
- Отслеживание изменений файла на диске.

### Редактирование
- Режим «Визуальный»: разметка спрятана вне строки с курсором, сохранение без потерь.
- Режим «Код»: подсветка markdown и живой предпросмотр с синхронной прокруткой.
- Панель форматирования и горячие клавиши, продолжение списков по Enter, Tab/Shift+Tab.
- Атомарное сохранение с сохранением кодировки и концов строк.

### Безопасность
- Белый список ссылок, блок протоколов, UNC, устройств, исполняемых файлов, bidi-подмены.
- Предупреждения о подмене адреса, видимый настоящий адрес до клика.
- Картинки из интернета — только по разрешению, без отправки учётных данных, без адресов локальной сети.
- Вставка только чистого текста, никакого OLE/RTF из буфера обмена.
- Поиск DLL только в System32, запрет DLL с сети, CFG, статический CRT.

### Установка
- Встроенный установщик: копия в `D:\Programs\vibe-mdViewer`, ассоциация `.md` в HKCU, системный диалог выбора программы, запись в «Удаление программ».
