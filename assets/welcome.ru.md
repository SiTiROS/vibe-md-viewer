# vibe-md-viewer

Быстрый просмотрщик и редактор Markdown для Windows. Без браузерного движка, без Edge, без интернета.

{{STATUS}}

## Как пользоваться

- Откройте `.md` двойным щелчком, через **Ctrl+O** или перетащите файл в окно.
- **Ctrl+1** — просмотр, **Ctrl+2** — визуальное редактирование, **Ctrl+3** — режим кода (исходник + предпросмотр).
- Правки **сохраняются сами** — через секунду после паузы в наборе, при переходе в просмотр и при уходе из окна (Ctrl+S — сохранить сразу).
- **Ctrl+F** — поиск, **F5** — перечитать файл, **Alt+←** — назад по ссылкам.
- Масштаб — кнопки **− 100% +** справа на панели, **Ctrl+колесо мыши** или **Ctrl+плюс / минус / 0**.
- Кнопка **→←** — текст во всю ширину окна или узкой колонкой. Текст в просмотре можно выделять мышью и копировать.
- Кнопка **EN / RU** — язык интерфейса.

## Редактирование

| Действие | Клавиши |
| --- | --- |
| Жирный / курсив / зачёркнутый | Ctrl+B / Ctrl+I / Ctrl+Shift+X |
| Заголовок 1–6, обычный текст | Ctrl+Shift+1…6, Ctrl+Shift+0 |
| Маркированный / нумерованный список | Ctrl+Shift+8 / Ctrl+Shift+7 |
| Цитата | Ctrl+Q |
| Код | Ctrl+E |
| Ссылка | Ctrl+K |

В визуальном режиме служебные символы (`**`, `#`, `](адрес)`) спрятаны и появляются только в строке, где стоит курсор. Файл всегда сохраняется как обычный markdown — без потерь.

## Безопасность

- HTML и скрипты внутри `.md` **не выполняются** никогда.
- Ссылки `javascript:`, `vbscript:`, `data:`, `ms-*:`, `search-ms:` и любые незнакомые протоколы заблокированы.
- Сетевые пути `\\сервер\...` заблокированы (защита от кражи хеша пароля Windows).
- Исполняемые файлы (`.exe`, `.bat`, `.lnk`, `.ps1`…) по ссылкам не открываются.
- Картинки из интернета загружаются только с вашего разрешения.
- Перед открытием ссылки её настоящий адрес виден внизу окна.

Подробности — в `docs/SECURITY.md` репозитория.
