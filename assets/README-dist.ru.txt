vibe-md-viewer {{VERSION}} — быстрый просмотрщик и редактор Markdown (.md) для Windows
==========================================================================

Требования: Windows 10 или 11, 64 бита. Больше ничего не нужно (ни Edge, ни .NET,
ни дополнительных библиотек).


УСТАНОВКА
1. Запустите vibe-md-viewer-{{VERSION}}-setup.exe.
   Если Windows покажет «Система Windows защитила ваш компьютер» (программа не
   подписана платным сертификатом) — нажмите «Подробнее» → «Выполнить в любом случае».
2. В окне установки нажмите «Установить» и подтвердите запрос прав администратора.
   Программа установится в C:\Program Files\vibe-md-viewer.
   Без прав администратора будет предложена установка только для вас.
3. Windows покажет окно «Каким образом вы хотите открыть этот файл?» — выберите
   vibe-md-viewer и отметьте «Всегда использовать это приложение».

Готово: файлы .md открываются двойным щелчком.


ОБНОВЛЕНИЕ
Запустите setup.exe новой версии и нажмите «Обновить». Удалять старую версию
не нужно; настройки и привязка файлов .md сохраняются.


УДАЛЕНИЕ
«Параметры» → «Приложения» → vibe-md-viewer → «Удалить»
(или запустите setup.exe и нажмите «Удалить»).


ГОРЯЧИЕ КЛАВИШИ
Ctrl+1 / Ctrl+2 / Ctrl+3 — просмотр / визуальное редактирование / код
Ctrl+O открыть (или перетащите файл в окно), Ctrl+F поиск, F5 перечитать, Alt+← назад
Правки сохраняются сами (пауза в наборе, переход в просмотр, уход из окна); Ctrl+S — сразу
Ctrl+B / Ctrl+I — жирный / курсив, Ctrl+K — ссылка
− 100% + справа на панели или Ctrl+колесо — масштаб
☀/☾ в правом верхнем углу — светлая/тёмная тема (по умолчанию тёмная)
→← / ←→ рядом — текст во всю ширину окна или узкой колонкой (по умолчанию во всю ширину)
EN / RU — язык интерфейса (по умолчанию английский)


БЕЗОПАСНОСТЬ
HTML и скрипты внутри .md не выполняются. Ссылки на программы, опасные протоколы
и сетевые пути заблокированы. Картинки из интернета загружаются только с вашего
разрешения. Перед кликом настоящий адрес ссылки виден внизу окна.
