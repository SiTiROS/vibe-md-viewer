Быстрый нативный просмотрщик и редактор Markdown для Windows 10/11.
Один небольшой `exe` (≈ 2.7 МБ), без браузерного движка (никакого Edge/WebView2/Electron), без интернета по умолчанию. Написан на Rust поверх Win32 и RichEdit.

**Скачать:** [последний релиз](https://github.com/SiTiROS/vibe-md-viewer/releases/latest) → `vibe-md-viewer-<версия>-setup.exe`. Exe собирается из исходников тега в GitHub Actions; рядом — контрольные суммы SHA-256.

- **Скорость.** Окно с готовым документом появляется примерно за 50–100 мс (замеры — в [docs/BUILD.ru.md](docs/BUILD.ru.md#замер-скорости)).
- **Картинки и ссылки.** Локальные картинки показываются сразу, картинки из интернета — по разрешению. Ссылки кликабельны, перед кликом внизу окна виден настоящий адрес.
- **Три режима:** просмотр, визуальное редактирование (как в текстовом редакторе), код (исходник + живой предпросмотр).
- **Безопасность.** HTML и скрипты из `.md` не выполняются; опасные протоколы, сетевые пути и исполняемые файлы по ссылкам заблокированы. Подробно — [docs/SECURITY.ru.md](docs/SECURITY.ru.md).
- **Два языка.** Интерфейс на английском (по умолчанию) и русском — кнопка **EN / RU** на панели.

## Установка

Нужна только Windows 10/11 x64. Установщик — `vibe-md-viewer-<версия>-setup.exe` со страницы [релизов](https://github.com/SiTiROS/vibe-md-viewer/releases) (или собранный самостоятельно `scripts\package.ps1` → `dist\`).

Установщик — это тот же exe: если имя файла содержит «setup», он открывает окно мастера установки (папка, «Открывать .md в vibe-md-viewer», «Запустить после установки», кнопки «Установить» / «Обновить» / «Удалить»). Тот же мастер открывается кнопкой «Установить…» на жёлтой плашке стартовой страницы или ключом `--setup`.

Установка — как у обычной программы: в Program Files, без ярлыков, служб и автозапуска.

1. Запустите `vibe-md-viewer-<версия>-setup.exe`.
2. Нажмите **«Установить»**:
   - Windows попросит подтвердить права администратора (UAC) — только на время установки;
   - программа копирует себя в `C:\Program Files\vibe-md-viewer` (для всех пользователей — только туда: так её не подменит обычный пользователь) и регистрируется для `.md`, `.markdown` и похожих расширений для всех пользователей, плюс запись в «Приложения и возможности»;
   - если прав администратора нет (рабочий ПК) — предлагается установка только для себя в `%LOCALAPPDATA%\Programs\vibe-md-viewer` без UAC;
   - затем открываются «Параметры Windows → Приложения по умолчанию»: в Windows 11 — страница vibe-md-viewer (назначьте его для `.md`), в Windows 10 — нажмите «Выбор стандартных приложений для типов файлов», найдите `.md` и выберите **vibe-md-viewer**. То же — со стартовой страницы: «Сделать программой по умолчанию для .md».

Сам просмотрщик всегда работает с обычными правами — повышенные права нужны только копии-установщику на несколько секунд.

Windows 10 не позволяет программам молча назначать себя «по умолчанию» — это защита системы, поэтому последний шаг — один клик пользователя.

exe не подписан сертификатом, поэтому на чужом компьютере после скачивания SmartScreen покажет «Неизвестный издатель» → «Подробнее» → «Выполнить в любом случае».

Альтернатива из консоли: `vibe-md-viewer.exe --install`. Удаление: «Параметры → Приложения» или `vibe-md-viewer.exe --uninstall`.

## Обновление

**Просто запустите `setup.exe` новой версии** и нажмите «Обновить» (или запустите новый `vibe-md-viewer.exe` — он сам спросит «Обновить 0.1.0 → 0.2.0?»). Для установки в Program Files — один запрос UAC:

- файл программы в папке установки подменяется (если старая версия открыта — она переименовывается в `vibe-md-viewer.old.exe`, продолжает работать до закрытия и удаляется при следующем запуске);
- записи реестра обновляются, путь и идентификатор программы не меняются — выбор «программы по умолчанию» для `.md` сохраняется, повторно Windows не спрашивает;
- настройки (`%APPDATA%\vibe-md-viewer\settings.ini`) не трогаются;
- после обновления сразу запускается обновлённая программа.

Удалять и устанавливать заново не нужно. Автообновления через интернет нет и не планируется — программа сама в сеть не ходит.

**С 0.1.x (vibe-mdViewer) на 0.2.0:** программа переименована в vibe-md-viewer. «Обновить» ставит её в папку `vibe-md-viewer` рядом с прежней, убирает прежнюю папку `vibe-mdViewer` (когда старая версия закрыта) и записи реестра со старым именем, а настройки переносит из `%APPDATA%\vibe-mdViewer` в `%APPDATA%\vibe-md-viewer`. Выбор «программы по умолчанию» для `.md` сохраняется.

### Что и куда пишется

| Что | Где |
| --- | --- |
| Программа | `C:\Program Files\vibe-md-viewer\vibe-md-viewer.exe` (без прав администратора — `%LOCALAPPDATA%\Programs\vibe-md-viewer`) |
| Настройки | `%APPDATA%\vibe-md-viewer\settings.ini` (переносная копия без установки — `data\settings.ini` рядом с exe) |
| Ассоциация `.md`, запись «Удаление программ» | `HKLM\Software\Classes`, `HKLM\Software\VibeMdViewer`, `HKLM\...\Uninstall\VibeMdViewer` (при установке «для себя» — то же в HKCU) |
| Ярлыки, кеши, службы, автозапуск | **ничего** |

Чужую программу «по умолчанию» для `.md` установщик не перебивает — выбор делает пользователь в системном окне. При удалении настройки в `%APPDATA%\vibe-md-viewer` остаются.

## Горячие клавиши

| Действие | Клавиши |
| --- | --- |
| Просмотр / визуальный / код | Ctrl+1 / Ctrl+2 / Ctrl+3, Esc — вернуться в просмотр |
| Открыть файл | Ctrl+O или перетащить файл в окно |
| Сохранить | **само** — через секунду после паузы в наборе, при переходе в просмотр, при уходе из окна и закрытии; Ctrl+S — сразу, Ctrl+Shift+S — сохранить как. Если файл тем временем изменила другая программа (git pull, другой редактор), автосохранение останавливается и ничего не затирает — Ctrl+S спросит, F5 перечитает |
| Поиск / дальше | Ctrl+F / F3 (Shift+F3 — назад) |
| Перечитать файл | F5 |
| Назад по ссылкам | Alt+← или Backspace (в просмотре) |
| Масштаб | кнопки −  100%  + справа на панели (100% — сброс), Ctrl+колесо, Ctrl+плюс / минус / 0 |
| Выделить текст в просмотре | протянуть мышью (Shift+щелчок — расширить), двойной щелчок — слово, Ctrl+A — всё, Ctrl+C — копировать |
| Прокрутка | колесо, стрелки, PgUp/PgDn, пробел — плавно, с частотой монитора (60/144 Гц…); Home/End — в начало/конец; последний абзац докручивается до середины экрана |
| Жирный / курсив / зачёркнутый | Ctrl+B / Ctrl+I / Ctrl+Shift+X |
| Заголовок 1–6 / обычный текст | Ctrl+Shift+1…6 / Ctrl+Shift+0 |
| Маркированный / нумерованный список | Ctrl+Shift+8 / Ctrl+Shift+7 |
| Цитата / код / ссылка | Ctrl+Q / Ctrl+E / Ctrl+K |
| Открыть ссылку в редакторе | Ctrl+клик |
| Язык интерфейса | кнопка **EN / RU** справа на панели (по умолчанию английский; запоминается, `lang=ru` в `settings.ini`) |
| Во всю ширину / узкая колонка | кнопка `→←` / `←→` справа на панели (запоминается); текст, блоки кода и линии всегда заканчиваются на одной правой границе; на очень широком мониторе колонка не шире 22 дюймов (2112 px при 100%) — по центру |

В списках Enter продолжает список, Enter на пустом пункте завершает его, Tab / Shift+Tab меняют уровень.

## Режимы

- **Просмотр** — отформатированный документ: заголовки, списки, задачи, цитаты, GitHub-предупреждения (`> [!NOTE]`), таблицы, блоки кода с подсветкой синтаксиса (Rust, C/C++/C#, Java, JS/TS, Go, Python, Shell, PowerShell, SQL, HTML/XML, CSS, JSON/YAML/TOML/INI, Lua, Ruby, diff), картинки, цветные эмодзи ✅ 🟡 ❌, сноски, front matter, безопасное подмножество HTML (`<img>`, `<br>`, `<b>`, `<kbd>`, `<details>`, `align="center"`…). Текст во всю ширину окна или узкой колонкой — переключатель на панели.
- **Визуальный** — редактирование «как пользователь»: служебные символы markdown спрятаны и появляются только в строке, где стоит курсор. Файл всегда остаётся обычным markdown, сохранение без потерь.
- **Код** — исходный markdown с подсветкой разметки слева и живой предпросмотр справа.

## Сборка из исходников

Rust stable (`x86_64-pc-windows-msvc`) и Visual Studio Build Tools с компонентом «Разработка классических приложений на C++»:

```powershell
cargo test --release          # юнит-тесты (часть — на настоящем RichEdit)
cargo build --release         # target\release\vibe-md-viewer.exe
powershell -ExecutionPolicy Bypass -File scripts\selftest.ps1 -Exe target\release\vibe-md-viewer.exe
```

Подробно (кеши внутри папки проекта, замеры, пакет для раздачи) — [docs/BUILD.ru.md](docs/BUILD.ru.md). Каждый коммит проверяет [CI](.github/workflows/ci.yml): тесты, сборка, самотест на живом окне. Релиз публикуется автоматически, когда CI проходит на новой версии из `Cargo.toml` ([release.yml](.github/workflows/release.yml)).
