# AGENTS.md — rules for contributors and AI coding agents

vibe-md-viewer is a fast, secure Markdown viewer/editor for Windows: Rust + Win32 + RichEdit, a single exe that installs as the default app for `.md`. The two priorities are **startup speed** and **security**. Read [README.md](README.md), [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and [docs/SECURITY.md](docs/SECURITY.md) before changing code.

## Stack (fixed)

- Rust (stable, `x86_64-pc-windows-msvc`), the `windows` crate, RichEdit (`msftedit.dll`), pulldown-cmark, the `image` crate with Rust decoders only, WinHTTP.
- **No browser engines**: no WebView2/Edge, Electron, CEF. No heavy dependencies or runtimes.
- New DLL imports go through `/DELAYLOAD` (see `build.rs`) unless they are KnownDLLs needed for the first paint — DLLs that aren't KnownDLLs would otherwise be loaded from the exe folder (DLL planting).

## Security rules (never weaken)

- RichEdit receives **only RTF generated by `render.rs`**, with full escaping of document text. Document text in the editors is set only through TOM `SetText` (plain text).
- Links go **only** through `links::classify` (allow list); images only through `images::resolve`.
- Paste is plain text only. Images from the internet load only with the user's permission.
- The viewer never runs elevated; only the installer copy (`--elevated`) does, and only for `C:\Program Files\vibe-md-viewer`.
- Any change to a security policy needs a test and an entry in `docs/SECURITY.md` (and `docs/SECURITY.ru.md`).

## Interface language

- English is the default, Russian is the second language (the EN/RU toolbar button, `lang=` in `settings.ini`).
- Every user-visible string must be bilingual: `tr!("English", "Русский")` → `&'static str`, `trf!("Saved {n}", "Сохранено {n}")` → `String` (use named placeholders). See `src/i18n.rs`.
- Code comments, test messages and self-test messages are in English. Keep them short and precise.

## Documentation (update together with the code)

- English is primary: `README.md`, `docs/ARCHITECTURE.md`, `docs/SECURITY.md`, `docs/BUILD.md`, `CHANGELOG.md`.
- Russian versions next to them: `README.ru.md`, `docs/*.ru.md`, `CHANGELOG.ru.md`. Keep both in sync.

## Build and checks

```powershell
. .\scripts\env.ps1            # keeps cargo caches and temp files inside the project folder
cargo test --release --locked   # unit tests (some draw on a real RichEdit control)
cargo build --release --locked
powershell -ExecutionPolicy Bypass -File scripts\selftest.ps1 -Exe target\release\vibe-md-viewer.exe
powershell -ExecutionPolicy Bypass -File scripts\bench.ps1 -Exe target\release\vibe-md-viewer.exe
```

- Visual checks: `--snapshot PNG [--size WxH]`; keep snapshots and temporary files in `.toolcache\` (git-ignored), not in the system temp folder.
- Speed matters: measure with `scripts\bench.ps1` (startup) and `scripts\profile.ps1` (theme/mode/zoom switches, scroll frame time) when touching rendering or layout.
- `.ps1` files are UTF-8 **with BOM** (Windows PowerShell 5.1 needs it for Cyrillic).

## Installation behaviour

- Installs like ordinary software: `C:\Program Files\vibe-md-viewer` + HKLM via UAC; without admin rights — `%LOCALAPPDATA%\Programs\vibe-md-viewer` + HKCU. Settings: `%APPDATA%\vibe-md-viewer` (a portable copy keeps them in `data\` next to the exe). No shortcuts, services or autostart.
- Registry keys `VibeMdViewer` and the ProgID `VibeMdViewer.Markdown` must not change: users' default-app choice (UserChoice) points to them.
- Don't run install/uninstall on a developer's machine from automated tooling.

## Releases

Bump `version` in `Cargo.toml`, add the section to both changelogs, push to `main`. When CI passes and that version has no release yet, GitHub Actions builds, tests, attests and publishes the release `vX.Y.Z` (`.github/workflows/release.yml`); the tag is created on the checked commit. A commit without a version bump releases nothing. Actions are official `actions/*` only, pinned by commit SHA.
